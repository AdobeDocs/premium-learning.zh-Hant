# Premium Learning資訊

探索您的訂閱權益、續約選項和學習使用情況報表。 選擇下方連結的頁面名稱以瞭解更多資訊。

* [訂閱權益與續約](/help/main-guide/premium-learning-subscription/subscription-benefits-and-renewal.md)：瞭解您的訂閱包含哪些內容，以及如何保持存取您的學習內容。
* [使用報告概述](/help/main-guide/premium-learning-subscription/utilization-reports/utilization-report-overview.md)：瞭解哪些使用報告涵蓋範圍、誰可以提出要求，以及包含哪些歷史資料。
* [瞭解您的摘要表](/help/main-guide/premium-learning-subscription/utilization-reports/utilization-report-summary-sheet.md)：瞭解關鍵量度、註冊趨勢、完成、出席和認證。
* [瞭解您的註冊詳細資訊表](/help/main-guide/premium-learning-subscription/utilization-reports/utilization-report-enrollment-details-sheet.md)：檢閱學習者註冊資料、課程進度、重要日期和出席詳細資料。
