# 瞭解您的註冊詳細資訊表

## 「註冊詳細資料」表顯示什麼？

**註冊詳細資料**&#x200B;工作表提供摘要工作表後面的詳細資料。 其中包含學習者資訊、課程詳細資料、進度、出勤率、完成狀態以及主要註冊和課程日期。

閱讀學習使用情況報告的「註冊詳細資料」索引標籤的快速參考。 此工作表是摘要工作表之後的資料 — 每個學習者註冊一列。

- **學習者/電子郵件** — 註冊對象。
- **形式** — 訓練格式：獨立ILT （即時講師課程）、同類群組（多工作階段計畫）或自訂步調/隨選。
- **格式** — 傳遞方式，例如虛擬教室或自行節奏。
- **產品** — 課程涵蓋哪些Adobe產品。 課程可列出多個專案。
- **課程/訓練** — 特定課程標題。
- **執行個體/工作階段** — 學習者已註冊的特定類別執行/工作階段（或無排程工作階段的自學進度內容的「預設執行個體」）。
- **狀態** — 學習者在該課程中的位置：已完成、進行中或未開始。
- **進度** — 十進位完成進度（1 = 100%完成，0 =未開始，值介於兩者之間，不完整）。
- **逗留時間（分鐘）** — 學習者已登入課程的分鐘數。
- **註冊日期** — 學習者註冊的時間。
- **已開始** — 學習者開始課程的時間（如果未開始則為空白）。
- **期限** — 目標完成日期（若已設定）。
- **已完成** — 學習者完成的日期/時間（如果有的話）。
- **逾期** — 標幟截止日期是否已超過而未完成。
- **類別傳遞狀態** — 類別本身是否已執行：已傳遞、已排程或進行中。 僅適用於ILT/同類群組；空白表示自學。
- **ILT/同類群組出席** — 學習者是否出席即時工作階段：已參加、部分參加、無顯示、已排程或進行中。 僅適用於ILT/同類群組。
- **類別開始/類別結束** — 已排定的即時工作階段日期。
- **Month-Year** — 類別/工作階段所在的月份。 這是摘要工作表上「按月註冊趨勢」表格的摘要。
- **時區** — 執行類別的時區。

## 一些注意事項

- 每一列=一個課程註冊，而非一個學習者。 有3個課程的學習者會出現3次。
- 自控進度列一律會顯示「類別傳送狀態」、「出席情況」、「類別開始/結束」和「時區」的空白 — 這些欄只會套用至即時工作階段。
