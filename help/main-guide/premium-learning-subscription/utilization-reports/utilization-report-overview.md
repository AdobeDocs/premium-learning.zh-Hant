# 使用率報表概述

瞭解Premium Learning訂閱的使用率報表，包括報表涵蓋的學習活動、誰可以要求這些報表、報表包含多少歷史資料，以及目前報表與先前報表不同的原因。


## 什麼是使用情況報告？

使用率報表可提供整個組織的學習活動檢視，包括註冊、課程完成、出勤率、認證及整體訓練使用情況。

## 誰會收到使用情況報表？

您可以透過企業聯絡點(POC)索取使用情況報表，POC會管理或監督您的Premium Learning訂閱。 個別學習者不會收到此報表。

## 每個月報表包含多少歷史資料？

每個月報表都是累積式的，並且從2026年6月開始包含所有可用資料。 未來的每一份報告都會以上一份報告為基礎，因此您可以在單一報告中檢視過去和目前的學習活動。 2026年6月標誌著轉換至目前的學習平台，因此來自舊平台的資料不會納入這些報表中。

## 為何報表不包含2026年6月前的資料？

每月使用報告包含目前學習平台的資料，從2026年6月開始。 舊版平台的歷史資料可在個別報告中使用。 企業連絡人可以透過[連絡我們](https://adobe.service-now.com/adls?category=10)來要求復本。

## 新的使用率報告為何與先前的報告不同？

新的使用報告產生自我們目前的學習平台，該平台使用與舊版平台不同的資料模型。 因此，某些欄位和資料點已變更。

更新的報告也包含其他先前未提供的深入分析，例如更詳細的完成資訊和學習者不秀的可見度，為您提供組織學習活動的更全面檢視。
