# 訂閱權益與續約

探索Premium Learning訂閱及Premium Learning +私人培訓訂閱包含的各種權益，從隨選教育到實作學習及專家支援，應有盡有。 瞭解您的組織如何更新您的訂閱，以持續存取您的學習內容。

## Premium Learning訂閱包含哪些優點？

**Premium Learning訂閱提供下列專案的存取權：**

- 全企業範圍存取Adobe的頂尖學習平台
- 不受限制地存取隨選教育影片
- 存取學習環境，以進行實作練習和實驗
- 依角色和產業區分的個人化同類群組學習歷程
- 存取所有虛擬公共思想領導力研討會（創新工作坊）
- 取得同類群組1:1專家後導師服務，協助疑難排解和特定環境問題
- 免費存取Adobe憑證憑證（請參閱下方附註）

**Premium Learning +私人訓練訂閱提供以下存取許可權：**

- 全企業範圍存取Adobe的頂尖學習平台
- 不受限制地存取隨選教育影片
- 存取學習環境，以進行實作練習和實驗
- 依角色和產業區分的個人化同類群組學習歷程
- 存取所有虛擬公共思想領導力研討會（創新工作坊）
- 取得同類群組1:1專家後導師服務，協助疑難排解和特定環境問題
- 免費存取Adobe憑證憑證（請參閱下方附註）
- 存取私人和個人化訓練
- 存取開啟的沙箱以在防故障的環境中練習

>[!NOTE]
>
> 免費認證憑單不適用於所有「存取」或「隨選學習訂閱」使用者（先前稱為Adobe數位學習服務）。

## 我的學習訂閱存取即將結束。 如何保持學習內容的存取權？

若要繼續對您的學習訂閱和內容進行不間斷的存取，請讓您的組織聯絡您的Adobe客戶經理。 他們可引導您瞭解可用的續約選項。
