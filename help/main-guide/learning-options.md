# 我有Premium Learning訂閱。 我可以存取哪些學習選項？

## 同類群組學習

同類群組學習融合了專家引導式指導、討論和真實世界應用程式，同時促進2-8週的共同發展、社群和協同合作。 與Adobe專家和您的同業進行即時學習。 在直播課程之間學習自控進度活動和測驗。 透過引導式的Capstone專案展示精通。 成功完成同類群組後，學習者將會取得完成徽章，並更接近認證整備程度。

參與同類群組：[開始前須知](/help/main-guide/cohorts/overview.md)

## 即時講師課程

我們的即時課程由專家講師帶領，與Adobe Experience Cloud產品團隊共同開發。 透過Premium Learning，我們的講師會透過產品沙箱中的實作練習，引導您完成互動式課程。 您將取得每個課程的投影片、活動指南和完成徽章。

參與即時講師課程：[開始前須知](live-instructor-course-readiness/overview.md)

## 隨選課程

根據您的進度表學習根據我們即時課程設計的課程 — 根據您的進度進行。 請利用我們要求的學習沙箱中的實作產品練習深入探討，並透過引導式活動、課程資料和完成徽章來強化您的技能。

這裡未列出問題？ [連絡我們](https://adobe.service-now.com/adls?category=8)。
