# 開始前須知：即時講師課程 — 概覽

在參加即時講師課程之前，請為成功的學習歷程做好準備。 選取連結的主題名稱（每個專案的第一個字）以跳至該區段。

* [準備即時講師課程](/help/main-guide/live-instructor-course-readiness/course-preparation/prepare-for-live-instructor-course.md)：瞭解註冊後的期望、如何存取您的課程環境，以及如何成功進行訓練。
* [加入即時講師課程工作階段](/help/main-guide/live-instructor-course-readiness/course-preparation/join-live-instructor-course-session.md)：瞭解如何在課日加入您的即時工作階段，包括如果您的行事曆邀請遺失時的備份步驟。
* [即時講師課程系統需求](/help/main-guide/live-instructor-course-readiness/system-requirements/live-instructor-course-system-requirements.md)：檢視適用於所有即時講師課程的Adobe Connect、硬體和軟體需求。
* [解決方案的其他系統需求](/help/main-guide/live-instructor-course-readiness/system-requirements/additional-system-requirements-by-solution.md)：檢閱AEM Edge Delivery Services Development、AEM Sites、Campaign、Experience Platform和Target的額外需求。
