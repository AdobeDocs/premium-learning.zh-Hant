# 準備即時講師課程

## 報名虛擬即時講師課程後，我還能期待什麼？

註冊後，您將會收到自動的確認電子郵件和行事曆邀請。 您的行事曆邀請包含個人化的會議室連結，您將使用該連結來參加培訓。 請&#x200B;**接受邀請**&#x200B;以儲存日期。

電子郵件傳遞秘訣：

* 學習相關電子郵件和行事曆邀請將來自[plsnore@adobe.com](mailto:plsnore@adobe.com) （Premium Learning訂閱無回覆電子郵件地址）。 將此電子郵件地址新增至您的連絡人或安全寄件者清單，以確保將電子郵件傳送至您的收件匣。
* 如果您遺漏電子郵件，請檢查您的垃圾郵件或垃圾郵件資料夾，以及任何次要收件匣標籤（例如Outlook中的&#x200B;**[!UICONTROL 其他]**&#x200B;標籤或類似的篩選檢視）。

## 報名現場講師課程後，我還能期待什麼？

註冊後，您將會收到自動確認電子郵件。 如果您收到行事曆邀請，請&#x200B;**接受邀請**&#x200B;以儲存日期。

**現場培訓：**&#x200B;請留意其他通訊內容，包括您的培訓地點和其他現場後勤服務的詳細資訊。 這些詳細資訊可能會在訓練日期附近分享。

電子郵件傳遞秘訣：

* 學習相關電子郵件將來自[plsnore@adobe.com](mailto:plsnore@adobe.com) （Premium Learning訂閱無回覆電子郵件地址）。 將此電子郵件地址新增至您的連絡人或安全寄件者清單，以確保將電子郵件傳送至您的收件匣。
* 如果您遺漏電子郵件，請檢查您的垃圾郵件或垃圾郵件資料夾，以及任何次要收件匣標籤（例如Outlook中的&#x200B;**[!UICONTROL 其他]**&#x200B;標籤或類似的篩選檢視）。

## Premium Learning是否提供示範或訓練例項？ 如何存取課程環境？

對於參加即時講師課程（虛擬或面對面）的客戶，您將獲得課程期間的沙箱環境。 您的講師會在課程的第一天提供執行個體的詳細資訊和存取權。

## 成功訓練的建議

* 準時，在其他時間安排其他會議。 請通知講師您是否需要出席會議。
* 等待閱讀電子郵件等時間
* 提出問題。 我們非常歡迎參與。 想法可以分享！
* 如果您在練習時需要協助，請告知講師。
* 不說話時請將麥克風設為靜音。
* 參與任何測驗、問題和討論。
