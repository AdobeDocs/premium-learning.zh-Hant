# 同類群組結構

## 同類群組結構如何？

**即時工作階段**

您每週都會參加兩場由Adobe專家主持的90分鐘即時會議，深入探討Adobe解決方案。 這些課程也讓您有機會透過群組討論和互動活動，與同類群組中的其他人交流。 有些星期會邀請嘉賓演講者分享最佳實務或真實使用案例。

**自訂進度活動**

在直播課程之間，您將完成自助式線上模組，其中包括閱讀、影片和實作練習，以幫助您套用所學內容。 每個模組結束後，小測驗可協助您檢查自己的理解。 我們建議每週預留2-4小時來完成線上學習與測驗。

**Capstone挑戰**

身為同類群組的一分子，您還將與一組同行共同作業Capstone挑戰專案。 這是一個在真實世界情境中運用您所學到一切知識的機會。 您的群組會提供簡短的簡報，以分享您的工作，並從Adobe講師和同業學習者那裡獲得意見回饋。
