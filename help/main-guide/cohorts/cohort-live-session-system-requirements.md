# 同類群組即時工作階段的系統需求

## 使用Adobe Connect做好準備

即時工作階段將使用Adobe Connect進行。 請務必依照這些查核點操作，以避免即時工作階段期間出現技術問題：

1. 執行此[診斷測試](https://training.adobeconnect.com/common/help/en/support/meeting_test.htm)，以確保Adobe Connect在您的系統上正常運作。
1. 請查閱Adobe Connect的[技術規格](https://helpx.adobe.com/adobe-connect/connect-tech-spec/12-10-technical-specifications.html)。
1. 您可以透過瀏覽器或案頭應用程式加入Adobe Connect。
a)如果已安裝案頭應用程式，而您遇到問題，請解除安裝Adobe Connect應用程式，然後使用[這裡](https://helpx.adobe.com/in/adobe-connect/connect-downloads-updates.html)提供的最新版本重新安裝它。

您會在行事曆邀請中找到個人化的虛擬會議室連結。 在訓練當天，我們建議在課程開始前5-10分鐘啟動連結。

### 其他資源

- [說明中心：技術支援](/help/main-guide/technical-support.md)
- [Adobe Connect支援部落格](https://blogs.connectusers.com/connectsupport/adobe-connect-best-practices/)

## 硬體需求

- 配備鍵盤和滑鼠的電腦或筆記型電腦
- 8 GB或以上的RAM，提供最佳的瀏覽器效能
- 最好使用第二台外接顯示器
- 最小解析度1280 x 768畫素
- 100 Mbps以上的網際網路連線

## 軟體需求

- 建議的網頁瀏覽器為Chrome或Firefox
- 能夠存取[Adobe CX Enterprise](https://experience.adobe.com/)的登入畫面（請參閱下面的備註）
- 訓練期間會提供登入資訊
- 存取文字編輯器
- 解壓縮封存(.zip)檔案的程式
- 讀取PDF的程式，例如[Adobe Reader](https://get.adobe.com/reader/)

>[!NOTE]
>
>請勿登入。 請直接測試您是否可以存取瀏覽器中的連結，而不需要貴公司的網路進行封鎖。 您可能會看到訊息「您的Adobe ID未連結至Adobe Experience Cloud解決方案帳戶」，這如預期所示。 此連結並非供學習者事先存取任何內容。 在課程的第一天，您的講師將提供登入的認證。
