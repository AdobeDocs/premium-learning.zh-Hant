# 同類群組 — 概觀

在Adobe Premium Learning同類群組中取得成功所需的一切。 選取連結的主題名稱（每個專案的第一個字）以跳至該區段。

* [同類群組結構](/help/main-guide/cohorts/cohort-structure.md)：瞭解同類群組的運作方式，包括每週的即時課程、自訂進度模組和測驗、Capstone挑戰賽，以及規劃時間。
* [參與率期望](/help/main-guide/cohorts/participation-expectations.md)：瞭解完成同類群組所需的條件，包括每週兩次的即時工作階段出勤率、自訂進度模組和測驗，以及Capstone挑戰。
* [註冊與設定](/help/main-guide/cohorts/enrollment-and-setup.md)：瞭解註冊後的預期情況，包括確認電子郵件、即時工作階段邀請、預先工作、沙箱存取和討論區設定。
* [您的學習歷程](/help/main-guide/cohorts/learning-journey.md)：瞭解如何追蹤出席情況、如何透過測驗和Capstone挑戰保持追蹤，以及期望同類群組結束時完成哪些工作。
* [同類群組即時工作階段的系統需求](/help/main-guide/cohorts/cohort-live-session-system-requirements.md)：檢視您即時工作階段的Adobe Connect、硬體及軟體需求。
* [社群](/help/main-guide/cohorts/community.md)：透過&#x200B;**[!UICONTROL 我的中心]**&#x200B;中的討論區，與您的同類群組、講師和主持人連絡。
* [同類群組支援](/help/main-guide/cohorts/support.md)：尋找遺失的行事曆邀請、從&#x200B;**[!UICONTROL 我的學習]**&#x200B;啟動即時工作階段，以及取得沙箱環境和Adobe Connect的說明。
