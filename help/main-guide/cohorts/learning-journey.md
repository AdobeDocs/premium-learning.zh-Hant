# 您的學習歷程

## 如何追蹤同類群組的出席情況？

僅根據即時工作階段的參與率來追蹤出席率。 如果您無法即時出席工作階段，之後觀看錄製內容就不會計入出席記錄。

## 為何需要即時出席？

即時工作階段提供錄製無法完整復寫的機會。 透過參加現場直播，您將能夠在互動式環境中提出問題、參與討論，並與同儕一起實習。 我們鼓勵所有人儘可能優先參與每個工作階段。

## 如何在同類群組期間保持追蹤？

每週的自學單元都包含小測驗。 這些說明可協助您確認對所涵蓋主題和概念的瞭解。

同類群組快結束時，您將完成約40個問題的最終評估測驗，以總結您的學習。

您也可以追蹤完成Capstone Challenge專案的進度。 此群組活動可讓您將學到的知識運用在真實世界的情境中。

## 同類群組結束時會發生什麼事？

最後幾週包括進行學習的Capstone挑戰賽，以及一些認證準備時間，讓您準備好參加Adobe認證考試。

同類群組完成徽章將於[我的成就](https://experienceleague.adobe.com/en/premium/my-achievements)中提供。
