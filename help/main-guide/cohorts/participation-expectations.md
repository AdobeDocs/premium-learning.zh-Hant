# 參與率期望

**即時工作階段是同類群組的核心部分，預計每週出席兩次。 僅根據即時參與率來追蹤出席情況。** 這些即時互動式會議讓您有機會與Adobe專家互動、提出問題、參與討論並與同業進行練習。 雖然可以檢閱工作階段錄製，但觀看錄製不會計入您的出席情況。

**完成點數需要Capstone專案與同級評審。** 透過引導式的Capstone專案展示精通。 將您的學習運用到現實世界的挑戰中，然後在結構化稽核工作階段中與同行交換意見回饋。 學習者必須完成Capstone專案才能獲得同類群組完成評分。

**自訂進度模組和測驗對於準備即時工作階段以及成功完成專案至關重要。** 在直播課程之間，根據您自己的步調靈活學習。 存取非同步模組、實作實驗室和討論活動，以加深您的理解，並在真實世界情境中套用重要概念。
